## Installation

Install CL SDK and its peer dependencies:

```bash
npm install @claritylabs/cl-sdk pdf-lib zod
```

<Callout type="info">
  CL SDK is published on [npm](https://www.npmjs.com/package/@claritylabs/cl-sdk) under the `@claritylabs` scope. It has no framework dependency — bring any LLM provider you prefer.
</Callout>

## Create provider callbacks

CL SDK uses plain callback functions instead of framework-specific model objects. Extraction needs `generateObject`; query, application, PCE, and agent prompt workflows also use `generateText`.

```typescript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

const generateText = async ({ prompt, system, maxTokens, taskKind, budgetDiagnostics, providerOptions }) => {
  const response = await client.messages.create({
    model: "claude-sonnet-4-6",
    max_tokens: maxTokens,
    system: system ? [{ type: "text", text: system }] : undefined,
    messages: [{ role: "user", content: prompt }],
  });
  return {
    text: response.content[0].type === "text" ? response.content[0].text : "",
    usage: { inputTokens: response.usage.input_tokens, outputTokens: response.usage.output_tokens },
  };
};

const generateObject = async ({ prompt, system, schema, maxTokens, taskKind, budgetDiagnostics, providerOptions }) => {
  const response = await client.messages.create({
    model: "claude-sonnet-4-6",
    max_tokens: maxTokens,
    system: system ? [{ type: "text", text: system }] : undefined,
    messages: [{
      role: "user",
      content: [
        ...(providerOptions?.pdfBase64
          ? [{ type: "document", source: { type: "base64", media_type: "application/pdf", data: providerOptions.pdfBase64 } }]
          : []),
        ...((providerOptions?.images as Array<{ imageBase64: string; mimeType: string }> | undefined)?.map((img) => ({
          type: "image",
          source: { type: "base64", media_type: img.mimeType, data: img.imageBase64 },
        })) ?? []),
        { type: "text", text: prompt },
      ],
    }],
  });
  const text = response.content[0].type === "text" ? response.content[0].text : "{}";
  return {
    object: schema.parse(JSON.parse(text)),
    usage: { inputTokens: response.usage.input_tokens, outputTokens: response.usage.output_tokens },
  };
};
```

For extraction calls, CL SDK uses `providerOptions` to carry source evidence into your callback:

- source-tree extraction passes `providerOptions.sourceSpans` and `providerOptions.sourceChunks`
- operational-profile and coverage-cleanup calls receive bounded source evidence in the prompt
- Docling document inputs are normalized into source spans before the source tree is built
- multimodal query calls may include `providerOptions.attachments`, `providerOptions.pdfBase64`, and `providerOptions.images`
- application and query workflows may include `providerOptions.sourceSpans` and `providerOptions.sourceChunks`

Your callback must preserve the provider options it supports. For source-tree extraction, the source evidence is text in the prompt and metadata in `providerOptions`; raw PDF bytes are not the primary extraction input.

Callbacks also receive optional `taskKind` and `budgetDiagnostics` metadata. Use `taskKind` for host-side routing/fallback decisions such as cheap classification, larger long-list extraction, review, query reasoning, application extraction, or PCE impact analysis. Use `budgetDiagnostics` for telemetry and escalation policies based on resolved token budgets or truncation-risk warnings.

See the [Provider Callbacks](/docs/getting-started/models) guide for examples with OpenAI, Vercel AI SDK, and other providers.

## Extract a document

Preprocess the PDF into source spans, then pass those spans to `createExtractor().extract()`. Extraction fails fast when neither `options.sourceSpans` nor a Docling input provides spans.

```typescript
import { buildPageSourceSpans, createExtractor } from "@claritylabs/cl-sdk";
import { readFileSync } from "fs";

// Load a PDF as base64
const pdfBase64 = readFileSync("./policy.pdf").toString("base64");

// Create the extractor with your structured-output provider callback
const extractor = createExtractor({ generateObject });

// Required for PDF inputs: provide source text spans from your parser/OCR layer
const pageOneText = "..."; // text from your PDF text/OCR pipeline
const sourceSpans = buildPageSourceSpans([
  { documentId: "doc-123", sourceKind: "policy_pdf", pageNumber: 1, text: pageOneText },
]);

// Run the source-tree extraction pipeline
const { document, sourceTree, operationalProfile, sourceChunks, chunks, tokenUsage, usageReporting } =
  await extractor.extract(pdfBase64, "doc-123", { sourceSpans });

console.log(document.carrier);       // "Hartford"
console.log(document.policyNumber);  // "GL-2024-001234"
console.log(sourceTree.length);       // canonical source hierarchy
console.log(operationalProfile);      // source-backed product facts
console.log(chunks.length);           // 0 on v3 source-tree extraction paths
console.log(sourceChunks.length);    // Source evidence windows for source retrieval
console.log(tokenUsage);             // aggregate provider-reported usage
console.log(usageReporting);         // calls with or without provider usage metadata
```

### Extract from a Docling document

If your host already runs [Docling](https://github.com/docling-project/docling), pass the serialized `DoclingDocument` JSON instead of the PDF. CL SDK does not install or invoke Docling directly; it consumes the parsed structure, derives source spans, and runs the same focused structuring pipeline over Docling page text.

```typescript
const { document, sourceSpans } = await extractor.extract({
  kind: "docling_document",
  document: doclingDocumentJson,
  sourceKind: "policy_pdf",
}, "doc-123");
```

## Query documents

Answer questions against stored documents with citation-backed provenance:

```typescript
import { createQueryAgent } from "@claritylabs/cl-sdk";

const agent = createQueryAgent({
  generateText,
  generateObject,
  documentStore,
  memoryStore,
  sourceRetriever,
});

const result = await agent.query({
  question: "What is the GL deductible?",
  conversationId: "conv-1",
});

console.log(result.answer);     // "The General Liability deductible is $1,000 per occurrence."
console.log(result.citations);  // [{ chunkId: "...", text: "...", pages: [3] }]
```

You can also attach inbound context directly to the question:

```typescript
const result = await agent.query({
  question: "What should we ask next about this damage, and is there any policy context?",
  conversationId: "conv-1",
  attachments: [
    {
      kind: "image",
      name: "damage.jpg",
      mimeType: "image/jpeg",
      base64: damagePhotoBase64,
    },
    {
      kind: "pdf",
      name: "coi.pdf",
      mimeType: "application/pdf",
      base64: coiPdfBase64,
    },
  ],
});
```

The query workflow interprets those attachments into evidence first, then uses classification to decide whether stored document retrieval is needed. Attachment-only and general questions can skip retrieval; document-backed questions still retrieve chunks and verify grounding before answering.

## Process an application

Handle insurance application intake with a bounded agentic workflow:

```typescript
import { createApplicationPipeline } from "@claritylabs/cl-sdk";

const pipeline = createApplicationPipeline({
  generateObject,
});

const { state } = await pipeline.processApplication({
  pdfBase64,
  applicationId: "app-1",
  sourceSpans,
});

console.log(state.fields);    // extracted and auto-filled fields
console.log(state.batches);   // topic-based question batches for user collection
```

Application processing plans optional backfill, context auto-fill, document lookup, batching, reply parsing, lookup, explanations, and next-batch email generation from the current state so unnecessary provider and storage calls are skipped.

## Build a PCE packet

Create a source-grounded policy change endorsement case and generate a review packet:

```typescript
import { createPceAgent } from "@claritylabs/cl-sdk";

const pce = createPceAgent({
  generateObject,
  sourceRetriever,
  executionMode: "auto",
});

const { state } = await pce.processChangeRequest({
  requestText: "Add the new van to the commercial auto policy effective June 1.",
});

const packet = pce.generateSubmissionPacket({ state });
console.log(packet.validationIssues);
```

## Add logging

Every pipeline accepts an `onProgress` callback for observability:

```typescript
const extractor = createExtractor({
  generateText,
  generateObject,
  onProgress: (message) => console.log(`[cl-sdk] ${message}`),
});

const { document } = await extractor.extract(pdfBase64, "doc-123", { sourceSpans });
```

Output:

```
[cl-sdk] Building source-native document tree...
[cl-sdk] Source-tree extraction complete.
```
