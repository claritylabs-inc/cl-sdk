[Clarity Labs](https://claritylabs.inc) builds deterministic AI agents for regulated industries, starting with commercial insurance.

CL SDK is the insurance intelligence layer behind those agents: a pure TypeScript library for extracting, reasoning about, and acting on insurance documents with deterministic scaffolding around model calls. It is provider-agnostic by design: bring any LLM via plain callback functions. No framework dependency.

The current 3.2 release line makes source-tree extraction the policy extraction path. Hosts preprocess PDFs into source spans with LiteParse, Docling, PDF.js, OCR, or another parser; CL SDK builds the canonical source tree from those spans and returns source-backed operational facts plus a compatibility `InsuranceDocument` projection.

## Install

```bash
npm install @claritylabs/cl-sdk pdf-lib zod
```

```typescript
import { buildPageSourceSpans, createExtractor } from "@claritylabs/cl-sdk";

const sourceSpans = buildPageSourceSpans([
  { documentId: "policy-123", sourceKind: "policy_pdf", pageNumber: 1, text: pageOneText },
]);

const extractor = createExtractor({ generateObject });
const { document, sourceTree, operationalProfile, chunks } =
  await extractor.extract(pdfBase64, "policy-123", { sourceSpans });

console.log(document.carrier);    // "Hartford"
console.log(sourceTree.length);    // canonical source hierarchy
console.log(operationalProfile);   // source-backed policy facts
console.log(chunks.length);        // 0 on v3 source-tree extraction paths
```
